# M4: 到達時間（TTS99）の比較

2026-10-11。**数字は断りが無いかぎり実測**。FPGA は K = 56 レーン（896 レプリカ）・125 MHz（M3 の最後の版）。

## 測り方

- **TTS99**: 機械を「R 個のレプリカを同時に走らせる 1 台」とみなす。長さ τ 周回の 1 回の実行に t 秒かかり、
  1 レプリカが目標に届く割合が p なら、1 回で少なくとも 1 つ届く確率は P = 1 − (1 − p)^R、
  TTS99 = t · ln(0.01) / ln(1 − P)（P ≥ 0.99 なら t）。τ は機械ごとに TTS99 が最小になるものを選ぶ
- **p**: どの機械も同じ種から同じ探索をする（ビット単位で一致）ので、アルゴリズムの性質として M4 の大きな実行
  （10,240 レプリカ、主種 1）で数え、全機械に使う。FPGA の 896 と A9 の 256 は、その先頭と同じレプリカ。
  **A9 の到達数は M4 の実行の先頭 256 と 28 件すべて一致**、FPGA の出力は期待値と全語一致（下記）
- **t**:
  - FPGA: CPU から測った DMA 込みの時間（回路のサイクルカウンタの時間も並べる）。R = 896 で固定
  - M4（Mac mini・10 コア）: `sa_fast` を 1,280 レプリカ（10 スレッド × ビットスライスの 128）で走らせた計算部分の時間。
    CPU はレプリカを減らせば 1 回の時間が縮むので、満たせる最小の数にした
  - A9（PYNQ-Z1・2 コア）: `sa_fast` を 256 レプリカ（2 スレッド × 128）
- **問題と温度**（温度は CPU 版の格子探索で選んだ）:

| 問題 | 頂点 / 辺 | 目標 | T0 → T1 | τ（周回） |
|---|---|---|---|---|
| ランダム 4 正則（`rr_n1024_d4_s1`） | 1024 / 2048 | 1774（最良既知）、1766（99.5%） | 0.8 → 0.2 | 100〜10,000 |
| G48 | 3000 / 6000 | 6000（二部グラフなので最適） | 1.0 → 0.4 | 100〜10,000 |
| G49 | 3000 / 6000 | 6000（同上） | 1.0 → 0.4 | 100〜10,000 |
| G50 | 3000 / 6000 | 5868、5872（最良既知は 5880） | 1.0 → 0.4 | 3,000〜100,000 |

- G50 の 5880 は、10 万周回・1,024 レプリカで **1 つだけ届いた**（実測）。数が少なすぎて TTS は出せないので、5868・5872 で比べる
- 道具: `sw/m4_bench.py`（Mac: スケジュール・M4 の実行・FPGA のジョブと期待値）、`host/mc_bench.py`（ボード: FPGA の照合と時間）、
  `host/a9_bench.sh`（ボード: A9）、`sw/m4_report.py`（集計）

## 正しさ

- FPGA: 19 ジョブ（4 問題 × τ）すべてで出力の全語が期待値と一致。**G-set（n = 3000）と、いちばん長い実行（G50・10 万周回・38.4 秒、48 億サイクル）も一致**
- サイクル数はすべて設計値 (WT + 1)·16 と一致（例: G50・10 万周回で 4,800,000,016）

## わかったこと

1. **難しい目標（G50）では、TTS99 の比は試行/秒の比とほぼ同じ。** FPGA は M4 の 3.8〜4.1 倍遅く、A9 の 26〜27 倍速い。
   どの機械も同じ探索をするので、試行回数で数えた TTS99（1.1e9〜1.1e10 試行）は共通で、差は速さだけで決まる
2. **易しい目標（ランダムグラフ・G48・G49）では、「1 回の実行の短さ」で決まる。** τ = 100 周回の 1 回で、どの機械も
   99% 以上の確率で届く。このとき TTS99 = 1 回の時間で、FPGA は M4 の約 2 倍遅い（試行/秒の比 4.1 倍より縮む）。
   FPGA の 1 回の時間は 1 周回 = n × 16 クロック（n = 1024 で 131 µs）で、レーンを増やしても縮まない（レプリカが増えるだけ）。
   M4 は 1,280 レプリカで 1 周回 70 µs ほど
3. **A9 との差は、易しい目標では 21〜22 倍、難しい目標では 26〜27 倍**で、試行/秒の比（64 倍）より小さい。
   A9 は 256 レプリカで 1 回が軽く、τ の刻みが粗い（100・300・1000…）ので 1 回の時間の下限に当たりやすい
4. 易しい目標は τ = 100（試した中でいちばん短い）で決まっている。もっと短い τ ならどの機械ももっと短くなるはずで、
   その比較は 1 回の時間の比（FPGA / M4 ≈ 2）になる見込み（試算）

## 言えないこと

- 温度スケジュールは問題ごとに 1 つ（CPU 版で選んだもの）。機械ごとに最適化したわけではないが、同じ探索をするので比較には影響しない
- p は 10,240 レプリカでの推定。G50・5872 の τ = 3,000 は 1 つしか届いておらず、その行の TTS は誤差が大きい
- 電力あたりの比較はまだ（電力計の入手待ち）
