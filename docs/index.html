Max-Cut on an FPGAFPGA で最大カット問題を解く

How fast can a small FPGA run simulated annealing for Max-Cut, compared with the same algorithm optimized just as hard on CPUs? A hand-written annealing engine on a PYNQ-Z1 (Zynq XC7Z020).

小さな FPGA で最大カット問題の焼きなましをどこまで速くできるか。同じアルゴリズムを同じだけ速くした CPU 版と比べます。 PYNQ-Z1（Zynq XC7Z020）に自作した焼きなましの回路です。
