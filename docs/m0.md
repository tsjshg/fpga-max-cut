## 正しさ

- `sw/check.sh`: sa.c と sa_check.py が 6 通りすべてで全行一致（n = 64・256、d = 3・4、目標到達あり）
- **Mac（M4・clang）と PYNQ-Z1（Cortex-A9・gcc 11 `-O3 -mcpu=cortex-a9 -mfpu=neon`）で、
  標準出力と最後の塗り分けが md5 で一致**
  - n = 1024・d = 4・64 レプリカ・200 周回、Mac は 4 スレッド・ボードは 1 と 2 スレッド
  - n = 1024・d = 3・32 レプリカ・200 周回
- sa.c は最後にカット値を数え直し、足し込んだ値と一致することを毎回確かめている

## 解の質（n = 1024・d = 4・乱数種 1 のグラフ、辺 2048 本）

初期の塗り分け（ランダム）のカット値は約 1024。偶数次数のグラフではカット値は必ず偶数になる。

**最良既知値 1774**: T0 = 0.8・T1 = 0.2・10 万周回・256 レプリカで、256 本すべてが 1774 に届き、1776 には 1 本も届かなかった。
最適であることの証明は無い。

### 頂点の順番と乱数（目標 1774、T0 = 0.8・T1 = 0.2・100 段、1024 レプリカ）

| τ（周回） | 順に回す・xorshift64 | ランダムに選ぶ・xorshift64 | 順に回す・splitmix64 |
|---:|---:|---:|---:|
| 100 | p = 0.022 / TTS99 20,272 | p = 0 / — | p = 0.021 / 22,225 |
| 300 | 0.188 / 6,615 | 0.010 / 140,779 | 0.200 / 6,185 |
| 1000 | 0.565 / **5,526** | 0.121 / 35,678 | 0.569 / 5,467 |
| 3000 | 0.751 / 9,938 | 0.464 / **22,162** | 0.783 / 9,037 |

TTS99 の単位は 1 レプリカあたりの周回数（× n で試行回数）。

- **順に回すほうが、TTS99 の最良どうしで約 4 倍良い**（5,526 対 22,162）。ランダムに選ぶ版は1試行に乱数を2回引くが、比べているのは試行回数なので、その費用は入っていない
- **xorshift64 と splitmix64 は誤差の範囲で同じ**（p の標準誤差は τ = 1000 で約 0.016）。xorshift64 で進める

### 温度（目標 1774、τ = 1000、1024 レプリカ）

| T0 \ T1 | 0.1 | 0.2 | 0.3 |
|---|---:|---:|---:|
| 0.6 | 7,012 | **5,126** | 5,979 |
| 0.8 | 5,571 | 5,526 | 7,676 |
| 1.2 | 6,953 | 6,078 | 11,169 |
| 2.0 | 7,218 | 8,028 | 15,514 |

最適は T0 = 0.6〜0.8・T1 = 0.2 のあたりで、なだらか。**標準のスケジュールは T0 = 0.8・T1 = 0.2・100 段 × 10 周回**とした。
このとき TTS99 は約 5,500 周回 ≒ 1 レプリカあたり 570 万試行。

C_target は 1774（100%）・1766（99.5%）・1758（99%）とする（その割合以上で最小の偶数）。

## CPU 版の速さ（未最適化の正解版。比較用の最適化版ではない）

比較用の最適化版は [cpu-fast.md](cpu-fast.md)（sw/sa_fast.c。M4 全コア 2.98e10・A9 2 スレッド 1.12e8 試行/秒）。
下の「分岐の予測外れが大きい」という見立ては、A9 では違い（主因は命令数）、M4 では温度しだいだった。

n = 1024・d = 4・64 レプリカ・200 周回。

| | 1 スレッド | 全スレッド |
|---|---:|---:|
| M4（10 コア） | 2.17e8 試行/秒 | 2.3e9 試行/秒（10 スレッド、256 レプリカ・10 万周回） |
| Cortex-A9 650 MHz | 9.0e6 試行/秒 | 1.8e7 試行/秒（2 スレッド） |

- 最初の版は `t % n` が 64 bit の剰余で、ARMv7 ではライブラリ呼び出しになり 3.96e6 試行/秒だった。
  周回と頂点の二重ループにして 2.3 倍になった（結果は書き換え前と md5 で一致）
- A9 は 1 試行に約 72 サイクル、M4 は 1 コアで約 20 サイクル（どちらもクロックからの換算で試算）。
  受け入れの分岐の予測外れが大きいと見ているが、まだ確かめていない
- **未最適化でも、M4 は design-draft 3.4 の FPGA の試算（2e9 試行/秒）を既に上回る**。
  M4 に勝つには、パイプラインの本数を大きく増やせる形（design-draft 8 章の案 (c)）が要る
